# 🤖 Бот для сайта «Все на свете»

> 🚀 Удобный и современный Telegram-бот для быстрой связи пользователей с администрацией сайта.

---

## 🌟 О проекте

Бот разработан для автоматизации общения с пользователями сайта **«Все на свете»**.  
Он помогает оперативно отвечать на вопросы, принимать обращения и сохранять данные для дальнейшей обработки.

💡 Основная цель — сделать коммуникацию простой, удобной и эффективной.

---

# ✨ Возможности бота

## 💬 Для пользователей

- 🔹 Ответы на часто задаваемые вопросы (FAQ)  
- 🔹 Быстрая связь с администрацией  
- 🔹 Удобная навигация через кнопки  
- 🔹 Автоматические ответы на команды  
- 🔹 Сохранение обращений в базе данных  

---

## ⚙️ Для администрации

Бот полностью настраивается под нужды проекта:

- 🔘 Управление кнопками меню  
- 👋 Настройка приветственного сообщения  
- 📜 Редактирование списка команд (Command List)  
- ❓ Обновление и добавление FAQ  
- 🗂 Просмотр и хранение обращений пользователей  

---

# 🛠 Технологический стек

## 📚 Используемые библиотеки

- 🧩 `PyTelegramBotAPI` — работа с Telegram Bot API  
- 🗄 `sqlite3` — хранение данных пользователей  
- 🧠 `sklearn` — обработка и анализ текста  

---

## 🖥 Среда разработки

- 🐍 `Python 3.11.9`  
- 💻 `Visual Studio Code`  
- 🔧 Git для контроля версий  

---

# 📊 Архитектура проекта

```text
Пользователь → Telegram → Бот → Обработка запроса
                                ↓
                          База данных (SQLite)
```
