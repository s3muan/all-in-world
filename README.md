# 🤖 Бот для сайта «Все на свете»

Добро пожаловать!  
Этот бот создан для удобной и быстрой связи с пользователями сайта.

---

## ✨ Что умеет бот

- 💬 Отвечать на часто задаваемые вопросы  
- 🗂 Сохранять все обращения пользователей в базу данных  

---

## ⚙ Возможности для администрации

Администратор может полностью настраивать бота:

- 🔘 Кнопки  
- 👋 Приветственное сообщение  
- 📜 Command-list  
- ❓ Ответы на часто задаваемые вопросы  

---

## 🛠 Используемые библиотеки

- `PyTelegramBotAPI`  
- `sqlite3`
- `sklearn`

---

## 🚩 Используемые инструменты 

- `python 3.11.9`
- `Visual Studio Code`
