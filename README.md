# Бот для сайта "Все на свете"
## Что умеет этот бот:
* Отвечать на часто задаваемые вопросы 
* Сохранять все обращения в базу данных 

## Возможности для администрации:
* Менять весь текст в боте:
1. Кнопки
2. Приветственое сообщение 
3. Command-list 
4. Ответы на часто задаваемые вопросы

## Библеотеки использующийся в боте:
1. [PyTelegrambotApi](https://pypi.org/project/telebot/)
